## 它是什么

生活指南是一个纯静态的四页站点：首页是入口，另有饮食、锻炼、睡眠三个专题。每个专题按一天的时间轴展开，把「该怎么做」落到具体数字、动作和边界条件。

四个页面都是独立的单文件 HTML，样式与脚本内联，不依赖构建工具、不请求外部资源；直接打开 `index.html` 就能离线阅读。

## 特性

- **一个入口，三个专题** —— 首页按「吃、练、睡」排列三张专题卡，附一句话主张与核心数字。
- **按一天展开** —— 从早餐、午餐、下午加餐，到训练时段、咖啡因截止和睡前环境，建议落在具体时间点。
- **每条建议有数字口径** —— 蛋白质克数、餐盘比例、每周运动分钟数、步数区间、睡眠时长与卧室温度都给出可执行范围。
- **依据可展开、可追溯** —— 39 处「研究怎么说」可展开，50 条编号来源在页末逐条可查，点击 R 编号即可跳转高亮。
- **三个专题互相跳转** —— 顶部导航常驻，正文末尾设「继续读」，从任一专题都能进入另外两个。
- **写明边界，不做绝对承诺** —— 标注锐痛、头晕、持续失眠等该停或就医的情况，区分观察性关联与因果结论。
- **四周执行计划** —— 每个专题都有从下限开始、逐步加量的四周安排。
- **深色阅读界面** —— 720px 正文宽度、粘性章节导航、时间轴与双栏卡片，长文也能扫读。
- **图标与状态可辨识** —— 三枚内联 SVG 线条图标对应饮食、锻炼、睡眠；当前专题在导航中高亮。
- **零依赖、零上传** —— 没有后端、没有账号、没有统计脚本，阅读行为不离开本机。

## 专题与核心口径

| 专题 | 场景 | 数字口径 | 说明 |
|---|---|---|---|
| 饮食 | 早餐蛋白质 | 25–30 g | 占全天蛋白质的约三分之一，别只吃碳水 |
| 饮食 | 餐盘比例 | 1/2 蔬菜、1/4 蛋白、1/4 主食 | 先装盘再吃，比吃到一半再控制更容易 |
| 饮食 | 晚餐与睡前 | 4–6 小时，至少 3 小时 | 给胃排空留时间，减少反流与入睡干扰 |
| 饮食 | 全天蛋白质 | 0.8–1.2 g/kg，每餐 20–30 g | 总量与分配都影响饱腹和肌肉维持 |
| 锻炼 | 有氧 | 150–300 分钟/周中等，或 75–150 分钟高强度 | 可以累计，不必一次做完 |
| 锻炼 | 力量 | ≥2 次/周 | 覆盖腿、推、拉、髋与核心，和有氧不可互相替代 |
| 锻炼 | 日常步数 | 7,000–8,000 步/天；老年人 6,000–8,000 | 步数与风险的关系来自观察性研究，不是硬指标 |
| 睡眠 | 固定起床 | 每天同一时刻，误差 ≤30 分钟 | 先锚定起床，再谈入睡 |
| 睡眠 | 咖啡因截止 | 睡前 6–8 小时；0 点睡最晚 14:00–16:00 | 半衰期个体差异大，敏感人群要更早 |
| 睡眠 | 卧室环境 | 16–19°C，光照 <1 lux | 温度与光线是可物理改造的变量 |

## 阅读与执行口径

```text
先做下限 → 稳定两周 → 再加剂量 → 记录反馈
```

- 下限优先：每周 150 分钟有氧、2 次力量、7–9 小时睡眠，做到下限就有收益；不足下限也不是无效，只是收益更少。
- 渐进加量：每周增加 5–10% 训练量或 1 组，比一次加到上限更可持续。
- 边界优先：出现锐痛、胸闷、头晕或心悸时停止并就医；持续失眠每周 ≥3 晚、超过 3 个月应优先考虑 CBT-I。
- 观察性关联不写成因果：步数、力量训练与死亡风险的数字来自队列研究，不能理解为「练到某个数字就一定延寿」。
- 体重变化看趋势：0.5–1 kg/周是常见可持续区间，不追求线性下降。
- 环境先于意志力：零食可见性、训练装备位置、卧室光照与温度，比临场硬扛更可靠。

## 开发说明

- 四个页面各自内联样式与脚本；改视觉变量时四个文件都要同步，避免专题页与首页漂移。
- 专题顺序固定为「吃、练、睡」：首页卡片、顶部导航、页内「继续读」、页脚链接都按此顺序。
- 新增或删除章节时，同步更新该页的粘性导航、滚动高亮与 `sitemap.xml`。
- 新增研究依据时，在正文加 `.ev` 摘要与 `.evref` 编号，并在 `#refs` 增加对应条目；编号不要跳号或重复。
- 修改站点地址或仓库名时，同步更新四页的 canonical、Open Graph、JSON-LD、页脚仓库链接与 `sitemap.xml`。
- 截图需在所有界面改动完成后重拍，README 两版引用同一张图。

## 浏览器支持

- 支持当前版本的 Chrome、Edge、Safari、Firefox；依赖 CSS 变量、Grid、`position: sticky`、`IntersectionObserver`。
- `backdrop-filter` 在个别旧版本不生效，导航仍保持可读背景，不影响功能。
- 可直接通过 `file://` 打开；所有页面互链使用相对路径，移动到任意目录仍可用。
- 不支持 IE；关闭 JavaScript 时依据展开与滚动高亮会失效，正文仍可读。
